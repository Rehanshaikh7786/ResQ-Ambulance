# GoldenHour SOS 🚑

Emergency reporting, AI-assisted injury triage, ambulance reservation, hospital approval, and live tracking.

See the complete application in the `GoldenHour_SOS/` directory. Setup instructions, feature flow, map configuration, tests, and prototype limitations are documented in `GoldenHour_SOS/README.md`.

> Academic prototype only. Not clinically validated and not for real emergencies. Call 112 / 108 for emergencies.
